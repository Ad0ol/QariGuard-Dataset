# QariGuard Dataset

## Overview

The QariGuard Dataset is a Quranic audio dataset developed to support research on audio deepfake detection, Quranic reciter identification, and multimedia security.

The dataset contains 400 Quranic audio files, including:

- 200 authentic Quranic audio recordings
- 200 AI-generated synthetic Quranic audio recordings

The recordings represent Quranic recitations from ten recognized Quranic reciters.
